# SMA4-Reusable-SaveQuit
Offline ROM patcher for Super Mario Advance 4: Super Mario Bros. 3 that makes Save &amp; Quit checkpoints reusable instead of disappearing after loading. Supports USA, USA/Australia Rev 1, Europe, Europe Rev 1, and European Wii U Virtual Console. Automatically detects ROM versions using SHA-1. No copyrighted ROMs included.
